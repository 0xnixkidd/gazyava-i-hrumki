Запустите Gazyava-i-Hrumki.exe внутри подходящего каталога:
x64 — обычные 64-битные ПК;
ia32 — 32-битные ПК;
arm64 — Windows на ARM.

Игра запускается без установки и без интернета.
Переносите весь каталог, а не только EXE: рядом находятся необходимые DLL и ресурсы.
F11 включает полный экран.
Мотик включается клавишей M или Пробелом за 20 лавэх.
Сборка не подписана цифровым сертификатом издателя.
