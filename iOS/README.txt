Версия для iPhone и iPad (PWA)

1. Разместите все файлы из этой папки рядом с index.html на HTTPS-хостинге.
2. Откройте адрес игры в Safari на iPhone или iPad.
3. Выберите «Поделиться» → «На экран „Домой“». Если есть переключатель
   «Открыть как веб-приложение», включите его. Нажмите «Добавить».
4. Первый раз откройте игру с иконки при включённом интернете, чтобы
   Safari сохранил игровые файлы для работы офлайн.

Для обновления замените файлы на том же HTTPS-адресе и снова откройте игру
с интернетом. Инструкция Apple:
https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/26/ios/26
