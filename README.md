# Газява и Хрумки

В версии 1.1.0 нефоры, слайдеры и лески появляются при включении мотика и пропадают, когда поездка заканчивается. На ПК мотик включается клавишей **M** (физическая клавиша **Ь** на русской раскладке) или **Пробелом**. Для поездки нужно 20 лавэх.

## Как запустить на iPhone или iPad

1. Для первого запуска разместите **содержимое** папки [iOS](iOS/) на любом статическом HTTPS-хостинге. Все файлы должны лежать рядом с `index.html`.
2. На устройстве откройте получившийся HTTPS-адрес в Safari. Уже на этой странице можно играть.
3. Чтобы добавить иконку, выберите **«Поделиться» → «На экран „Домой“»**. Включите **«Открыть как веб-приложение»**, если такой переключатель есть, и нажмите **«Добавить»**. [Инструкция Apple](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/26/ios/26)
4. Первый раз откройте игру с иконки при включённом интернете. После загрузки ресурсов она сможет работать офлайн, пока Safari хранит файлы игры.

В этой папке поставляется веб-версия (PWA). Для обновления уже установленной игры замените файлы на том же хостинге и повторно откройте её с интернетом.

## Другие сборки

- **Android** — установите [APK](Android/Gazyava-i-Hrumki.apk).
- **Windows** — запустите `Gazyava-i-Hrumki.exe` из папки своей архитектуры в [Windows](Windows/).
- **Linux** и **macOS** — выберите архив под свой процессор. Порядок запуска указан в [README для Linux](Linux/README.txt) и [README для macOS](macOS/README.txt).
- **iOS** — откройте [iOS/index.html](iOS/index.html) в браузере с WebGL.
