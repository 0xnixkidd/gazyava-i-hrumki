Газява и Хрумки 1.1.0 — сборки из source/index (2).html

Windows/ — переносимые приложения x64, ia32 и arm64. Запускайте EXE из
соответствующей папки; все соседние файлы обязательны.
Linux/ — архивы tar.gz для x64, arm64 и armv7l.
macOS/ — ZIP с приложением .app для Intel x64 и Apple Silicon arm64.
Для macOS требуется локальная ad-hoc-подпись: команда указана в macOS/README.txt.
Android/ — универсальный подписанный APK для Android 6.0+.
iOS/ — веб-версия PWA для Safari; нативного IPA нет.
Web/ — общая браузерная версия, также для других ОС с WebGL-браузером.

Игра использует локальную Three.js r128. Интернет для игрового процесса
не нужен. В копиях для сборки убрана загрузка внешних Google Fonts,
используются системные шрифты.
Настольные приложения включают Electron 33.4.11, как ветка исходного проекта.
На macOS/Windows нет коммерческой подписи издателя.
Android APK подписан локальным тестовым ключом для ручной установки;
при первой локальной сборке создаётся ключ build-tools/local-test.keystore.
Для установки обновления поверх существующего APK нужен тот же ключ.

Проверки:
- Windows x64: фактический запуск, WebGL, меню и начало раунда с таймером.
- APK: проверены подпись v1/v2/v3, манифест, DEX и игровые файлы.
- Остальные настольные варианты: содержимое пакетов, права файлов,
  символические ссылки macOS, совпадение встроенного app.asar.
- На Android-устройстве, Linux и macOS игра здесь не запускалась.
Контрольные суммы артефактов: SHA256SUMS.txt.

Повторная сборка в Windows PowerShell 7:
$env:JAVA_HOME = 'C:\путь\к\jdk'
.\build-tools\build-all.ps1
Нужны Node.js/npm, Python 3.11+ и JDK. Для чистой копии проекта установите
пакеты Android SDK platforms;android-35 и build-tools;35.0.0 с помощью
sdkmanager и укажите build-tools/android-sdk как --sdk_root.
Скрипты и lock-файл зависимостей сохранены.
Загрузка Electron проверяется по официальным SHA-256:
https://github.com/electron/electron/releases/tag/v33.4.11
Android build tools:
https://developer.android.com/tools

Поддержка иных нативных ОС (например, FreeBSD) в приложенных Electron-
бинарниках отсутствует. Для них предусмотрена браузерная версия Web.
