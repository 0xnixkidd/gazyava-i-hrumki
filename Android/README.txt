Gazyava-i-Hrumki.apk — установочная офлайн-игра для Android 6.0 и новее.
Скопируйте APK на устройство и откройте его; при запросе Android разрешите
установку приложений из выбранного источника.
Используется системный Android System WebView с поддержкой WebGL.
Сборка универсальна для процессоров: собственных нативных библиотек нет.
Подпись локальным тестовым ключом, APK проверен apksigner (v1/v2/v3).
Это пакет для ручной установки, не релиз для Google Play.
Проверка на физическом Android-устройстве в этом окружении не проводилась.
